# Ethan Jinks — Portfolio

A personal site for projects, internships, coursework, and other experience. Built with React, TypeScript, and Vite.

## Develop

```bash
npm install
npm run dev
```

## Edit the content

Biography, experience, projects, education, skills, and contact details live in `src/content.ts`. Add a LinkedIn URL on `profile.linkedIn` when you want that link to appear.

## Production

```bash
npm run build
npm run preview
```

The static build is written to `dist/`.
